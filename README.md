### kolyps0.github.io
my portfolio, built as an interactive terminal. visit it at [kolyps0.github.io](kolyps0.github.io) and type `help`. plain HTML, CSS and JavaScript, no build step and no dependancies.

**files**
|file|what it does|
|---|---|
|`index.html`|page shell and theme setup|
|`style.css`|styling, black and white only|
|`content.js`|everything about me, the file to edit|
|`terminal.js`|the terminal stuff|

**features**
- commands: `about`, `projects`, `homely`, `now`, `stack`, `links`, `neofetch`, `ls`, `cat`
- light and dark mode (`theme` command or the button), remembered between visits
- command history with the arrow keys, tab completion, `ctrl+l` to clear

**editing**
change the text in `content.js`. new project: copy a line in `projects`. new command: add it to `extra`.
